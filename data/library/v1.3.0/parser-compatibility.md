# HomePrep parser compatibility

The current HomePrep Library parser was copied into an isolated workspace folder. The copy used content version 1.3.0 and an explicit TypeScript import extension for Node 24. All 24 core cards, all 3,714 review index entries, all 19 detail payloads and their evidence and corrections parsed without rejection. Entry IDs and order matched the payloads. No browser or signed-in UI testing was performed during this handoff.
